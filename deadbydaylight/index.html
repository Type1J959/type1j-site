Does the Type 1 J Dead by Daylight Hub include recommended builds for every Killer? ▾

Yes. All 44 Dead by Daylight Killers include a tailored 4-perk recommended meta build you can inspect on their character card and load directly into the Build Planner with one click, complete with automatic synergy detection.

How does the 0–100 Prestige and missing perk access warning work? ▾

When you track which Killers and Survivors you own and set their Prestige level (0–100), the Build Planner automatically checks every perk you equip. If a loadout uses a teachable perk from a character you haven't unlocked or reached Prestige 1 on yet, it displays a clear warning showing which character to unlock or prestige.

Can I save multiple Survivor and Killer loadouts and share them in chat? ▾

Yes. You can save unlimited custom Killer and Survivor loadouts locally or to your free Type 1 J cloud account, and use the Copy for Chat button to share any 4-perk build in Twitch chat, YouTube comments, or Discord.
